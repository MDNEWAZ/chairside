# Fonts

Self-hosted latin subsets, served from `/fonts/` so `index.html` can preload them. All three are licensed
under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows bundling with software.

| File | Family | Copyright |
|---|---|---|
| `inter-latin-var.woff2` | Inter | The Inter Project Authors (https://github.com/rsms/inter) |
| `fraunces-latin-var.woff2` | Fraunces | The Fraunces Project Authors (https://github.com/undercasetype/Fraunces) |
| `jetbrains-mono-latin-var.woff2` | JetBrains Mono | The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) |

Files were taken from the Fontsource variable packages (`@fontsource-variable/*` 5.3.0).
